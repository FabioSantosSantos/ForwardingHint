Forwarding Hint for Named Data Networking (NDN)

Overview

This project proposes a new NDN strategy Forwarding called Forwarding-Hint that is a hint-based mechanism to improve data forwarding
efficiency in Named Data Networking (NDN) environments mainly using NDVRv2 probabilistics routes.

The solution enhances traditional forwarding strategies by embedding path guidance information into Interest packets,
enabling routers to make more informed forwarding decisions, especially in multi-path and cyclic topologies.
